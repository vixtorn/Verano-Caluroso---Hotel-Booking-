# Verano Caluroso — Hotel Booking Demo

Verano Caluroso is a minimal full-stack hotel booking project designed for learning and demonstration purposes. The project combines a static frontend with a lightweight Express and SQLite backend to simulate a basic hotel reservation flow.

Users can check room availability by date range, create reservations, and receive generated reservation IDs. The backend manages nightly room inventory, seeded room data, and TRY-based pricing, while the frontend provides simple marketing pages and a booking interface.

## Tech Stack

* **Frontend:** HTML, CSS, JavaScript, Flatpickr
* **Backend:** Node.js, Express, better-sqlite3
* **Database:** SQLite
* **Currency:** Turkish Lira
